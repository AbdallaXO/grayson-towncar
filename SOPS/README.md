# SOPs (Standard Operating Procedures)

This folder holds our team SOPs. Each one is a simple, step-by-step guide for how we do a specific task, written in plain English so anyone can follow it.

## How to use this folder
- One file per procedure.
- Keep them short and clear. If a step changes, update the file and bump the "Last updated" date at the top.
- When you add a new SOP, add it to the list below.
