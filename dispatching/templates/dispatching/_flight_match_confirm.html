{% comment %} Shared flight-match client for every "match pickup to flight" button. Include this once per page that has such a button, then call: matchFlightTime(legId).then(function (data) { if (data.cancelled) { ...restore the button...; return; } if (data.success) { ...refresh... } else { alert(data.error); } }); Why it exists: the server now refuses a bare match when the flight lands on a different calendar day than the pickup, and answers 409 with needs_confirmation="wrong_day". Five separate call sites would otherwise each have to grow their own dialog, and any one that didn't would just surface "could not update leg time" — hiding the single most important thing the dispatcher needs to decide. {% endcomment %}
