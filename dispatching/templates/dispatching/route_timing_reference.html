How to Read This Page
Dwell Time (Gate → Pickup)

Time from flight landing to driver picking up the passenger. Only for airport arrivals.

Drive Time (Pickup → Drop)

Time from picking up to dropping off the passenger.

P75 = Scheduler Value USED BY SCHEDULER

75% of trips finish within this time. The gold highlighted P75 value is what the scheduler uses for clearing estimates.

Confidence: High 20+ trips Medium 10-19 Low 5-9 None under 5. Click the sample count to view individual legs and exclude bad data.
